# alpha-mini-team-4

Alpha Mini Teaching Assistant 🤖📚


This project transforms the Alpha Mini robot into an interactive Teaching Assistant capable of engaging with students through multiple educational and wellness tasks. Designed to support classroom and remote learning environments, the assistant can:

📖 Tell Stories – Narrates educational and entertaining stories to captivate young learners.

❓ Conduct Quizzes – Asks questions and evaluates responses to reinforce learning through interactive quizzes.

🧍‍♂️ Take Attendance – Detects and records student presence, streamlining classroom management.

💪 Guide Workouts – Leads students through fun physical activities to encourage movement and wellness.
